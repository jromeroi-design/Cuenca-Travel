# Cuenca Travel - Portal Turístico de Cuenca

Sitio web desarrollado para la agencia turística **Cuenca Travel**, enfocado en la difusión del patrimonio colonial, natural y gastronómico de Cuenca (Azuay, Ecuador).

## Información del Estudiante
- **Estudiante:** Joan Pablo Romero Intriago
- **Destino Asignado:** Cuenca - Azuay
- **Materia:** Diseño de Sitios Web

## Estructura del Sitio
- **Inicio (`index.html`):** Identidad visual, Hero editorial y pilares turísticos.
- **Destinos (`destinos.html`):** 6 atractivos emblemáticos en tarjetas 3D interactivas.
- **Servicios (`servicios.html`):** 4 paquetes y excursiones con precios referenciales.
- **Nosotros (`nosotros.html`):** Historia, misión, visión, valores y motivos para visitar el destino.
- **Contacto (`contacto.html`):** Formulario semántico validado para solicitudes y reservas.

## Tecnologías Utilizadas
- HTML5 Semántico
- CSS3 (Flexbox, CSS Grid, 3D Transforms, Media Queries)
- Git & GitHub Pages
